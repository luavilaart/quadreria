# Spanish and English

quadreria ships in Spanish and English. Spanish is written with **voseo** (vos), as spoken in Honduras: "Entrá", "Elegí", "¿Qué querés hacer?", "Probá otro filtro".

## Where the language comes from

Lovable's `TaxonomyProvider` owns the language. The ES/EN button in the site header sets it, and the Spanish `/es/medios/...` pages set it to Spanish. There is no second language system.

The choice is not saved yet. A full page reload starts in English again.

## Where copy lives

| File | What it holds |
| --- | --- |
| `src/i18n/en.ts` | English UI copy. Its shape is the `Copy` type. |
| `src/i18n/es.ts` | Spanish UI copy. Typed as `Copy`, so a missing key fails the build. |
| `src/i18n/accounts.ts`, `accounts.es.ts` | Sign-up quiz, studio and account copy. |
| `src/i18n/taxonomy.ts` | Lovable's mediums, specialties and taxonomy screens, in both languages. |
| `src/i18n/index.ts` | `useT()`, `useFormat()`, `copyFor()`. |

## Rules for new code

- In a component, read copy with `const t = useT()`. Taxonomy screens keep using `c` from `useTaxonomy()`.
- Show stored values through `useFormat()`: `f.city()`, `f.eventType()`, `f.price()`, `f.date()`, `f.service()`.
- Copy that needs a name or number inside it is a small function, for example `t.event.left(spots, capacity)`.
- Artist content (titles, bios, FAQ) is shown as the artist wrote it. It is not translated.
- Write Spanish with vos. The tests fail on common tú forms.

## Not done yet

- Page titles and meta tags are English. `head()` runs outside React and cannot see the toggle. `copyFor(langOf(match.context))` will switch them once the language is in router context.
- Root "page not found" and error screens are English.
- Saving the language choice across reloads.
- Bilingual database fields for the blog and taxonomy, once those tables exist.

## Tests

`src/test/i18n.test.ts` checks that both languages have the same keys, that no Spanish string is empty, that all Spanish copy (including the taxonomy copy) uses vos, and that every city and event type has a Spanish label.
